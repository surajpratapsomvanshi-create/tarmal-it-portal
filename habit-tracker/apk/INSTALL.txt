https://surajpratapsomvanshi-create.github.io/atomic-habits/AtomicHabits.apk

- https://surajpratapsomvanshi-create.github.io/atomic-habits/download/AtomicHabits.apk

On Android, your browser may ask you to allow **Install unknown apps** for that browser before the APK can install.

## App URL (current / install this)

https://surajpratapsomvanshi-create.github.io/atomic-habits/

Open that link in Chrome on your phone for the installable PWA, or install the APK above.

## Install the APK on your phone

1. Open one of the download links above on your Android phone (or copy **AtomicHabits-github.apk** from this folder).
2. Open the downloaded APK and allow **Install from unknown sources** / **Install unknown apps** if asked.
3. Open the app - it loads https://surajpratapsomvanshi-create.github.io/atomic-habits/

If Android refuses to install over an older Atomic Habits build, uninstall the old app first, then install this APK (same package id `com.atomichabits.tracker`, same signing key as prior builds).
